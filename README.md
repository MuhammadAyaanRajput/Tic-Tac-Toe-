# 🎮 Tic Tac Toe – Java Console Game

A clean and interactive **command-line Tic Tac Toe game** built using **Java**, designed for two players. The game follows classic Tic Tac Toe rules and demonstrates strong fundamentals of **object-oriented programming** and **game logic implementation**.

---

## 🧩 About the Project

This project is a console-based implementation of the classic **Tic Tac Toe** game. Two players take turns entering row and column values to place their symbols (`X` and `O`) on a 3×3 board.

The program dynamically displays the board after every move, validates user input, checks for winning combinations, and determines draw conditions when the board is full.

---

## 🚀 Key Features

* 🎯 Two-player gameplay
* 🖥️ Console-based user interface
* 🔁 Turn-based logic
* ❌ Invalid move handling
* 🏆 Automatic win detection
* 🤝 Draw detection
* 🧱 Object-oriented design for better code structure

---

## 🛠️ Tech Stack

* **Language:** Java
* **Concepts Used:**

  * Object-Oriented Programming (OOP)
  * 2D Arrays
  * Loops and Conditional Statements
  * Encapsulation
  * User input handling with `Scanner`

## ▶️ How to Run

1. Ensure **Java JDK** is installed.
2. Clone the repository:

   ```bash
   git clone https://github.com/your-username/tic-tac-toe-java.git
   ```
3. Navigate to the project directory:

   ```bash
   cd tic-tac-toe-java
   ```
4. Compile the source files:

   ```bash
   javac *.java
   ```
5. Start the game:

   ```bash
   java Main
   ```

---

├── Main.java        # Game entry point and main loop
